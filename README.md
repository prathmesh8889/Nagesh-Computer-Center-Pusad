# Nagesh Computer Centre Pusad

Responsive multipage website (Home, Courses, About, Admissions, Contact) with lightweight 3D CSS animations, WhatsApp enquiry, and Vercel route rewrites.

No server or secret keys required. Open `index.html` with a local HTTP server for routing; deploy root as Other framework to Vercel.

Before public launch, verify address, phone, course list and timings with the business.
